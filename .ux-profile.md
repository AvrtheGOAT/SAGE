# UX profile: SAGE family dashboard
<!-- Draft written from the setup-ui-ux-skills recommended defaults. Edit freely. -->

## Aesthetic reference
**Stripe**: refined typography, balanced depth, clear data. Layout and accent follow the team's Stitch design.

## Theme
- Light and dark mode, toggle in the top bar; first visit follows the device setting, choice is remembered.
- Dark mode is neutral graphite, never navy/blue.
- One accent hue (cyan, from the Stitch design) for active nav, links, focus and primary buttons only.
- Status colours: green = OK, amber = attention, red = urgent, sky = info. Soft tinted backgrounds, never full-saturation fills except the red emergency actions.
- All colours live as CSS variables in `frontend/index.html` (`:root[data-theme=...]`).

## Typography
- Headings: Plus Jakarta Sans. Everything else: Inter. Two families only.
- Weights: 400 / 500 / 600 only. Nothing at 700+.
- Sizes: meta 12px (floor), secondary 14px, body 16px; headings on the Major Second scale (h4 18, h2 22.8, h1 28.8, metrics 32.4).
- Line-height: headings 1.1-1.25, body 1.5-1.55.

## Banned
- Glassmorphism / backdrop blur, neon or glowing borders, coloured drop shadows
- Decorative gradients, rainbow CTAs
- Cartoon empty-state illustrations
- Mono uppercase "techy" labels for ordinary UI text
- Showing hardware data the prototype doesn't have as if it were live

## Accessibility
**WCAG 2.1 AA**: text contrast at least 4.5:1, 44px touch targets, visible focus ring, reduced-motion respected.

## Voice
**Warm and human-centred.** Plain words a worried family member understands at a glance. Refer to the resident by name. Never blame the user in errors; always say what to do next.

## Icons
**Material Symbols Outlined** (Google Fonts). One set only; no emoji as icons.
