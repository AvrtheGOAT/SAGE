# UX profile: SAGE family dashboard
<!-- Draft written from the setup-ui-ux-skills recommended defaults. Edit freely. -->

## Aesthetic reference
**"Letter from home"** (Hue skill: `.claude/skills/sage-design/`): warm paper, ink-dark text, one fountain-pen blue. Calm surface, urgent payload.

## Theme
- Light and dark mode, toggle in the top bar; first visit follows the device setting, choice is remembered.
- Light is warm paper (#F6F2EA); dark is lamp-lit charcoal (#171513), never navy/blue.
- One accent, ink-blue (#2D4F9E light / #9DB6F2 dark), for active nav, links, focus, primary buttons and info. Nothing else.
- Status colours: green = OK, amber = attention, red = urgent. Soft tinted backgrounds, never solid fills except the red emergency actions.
- All tokens live in `frontend/css/sage.css`; Tailwind names map to them in `frontend/js/tw-config.js`.

## Typography
- Titles and names: Newsreader 500 (serif). Everything else, including every number, label and button: Hanken Grotesk 400/500/600.
- Scale ratio 1.2: meta/label 13, secondary 14, body 16, card title 20, section 24, screen title 28, metric 34.
- Line-height: headings 1.1-1.25, body 1.5-1.55. Sentence-case labels, never tracked capitals.

## Banned
- Glassmorphism / backdrop blur, neon or glowing borders, coloured drop shadows
- Decorative gradients, rainbow CTAs
- Cartoon empty-state illustrations
- Mono uppercase "techy" labels for ordinary UI text
- Showing hardware data the prototype doesn't have as if it were live

## Accessibility
**WCAG 2.1 AA**: text contrast at least 4.5:1, 44px touch targets, visible focus ring, reduced-motion respected.

## Voice
**Warm and human-centred.** Plain words a worried family member understands at a glance. Refer to the resident by name. Never blame the user in errors; always say what to do next.

## Icons
**Material Symbols Outlined** (Google Fonts). One set only; no emoji as icons.
